# Used Car Price Prediction - Assignment 3

## Dataset Overview
This project uses the Used Car Price Prediction dataset to perform Exploratory Data Analysis (EDA), Data Cleaning, and Feature Engineering.

## Data Quality Issues Identified
- Missing values in fuel_type, accident, and clean_title.
- Price and milage were stored as text.
- Duplicate records were checked and removed if found.

## Cleaning Techniques Applied
- Converted price to numeric.
- Converted milage to numeric.
- Filled missing values using mode and "Unknown".
- Removed duplicate records.

## Feature Engineering
Created five new features:
1. Car Age
2. Mileage Per Year
3. Luxury Brand Indicator
4. Price Category
5. Vehicle Age Category

## Five Key Insights
1. Most cars belong to a few popular brands.
2. Newer cars generally have higher prices.
3. Luxury brands are usually more expensive.
4. Mileage influences vehicle price.
5. Missing values were successfully handled before analysis.
